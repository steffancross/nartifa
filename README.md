# NARTIFA

Artist site: quiz, artworks, globe of visitor photos. Payload 3 + Next.js on Cloudflare Workers (D1, R2, OpenNext).

Started from Payload's [`with-cloudflare-d1`](https://github.com/payloadcms/payload/tree/main/templates/with-cloudflare-d1) template.

- How it's built: `specs/Nartifa Build Spec/`
- What it looks like: `specs/Nartifa Design Spec/`
- Progress: `specs/NARTIFA Build Checklist.md`

Node 24 (`.nvmrc`), pnpm.
